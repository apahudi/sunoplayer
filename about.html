Tentang aplikasi

Pemutar playlist Suno

Aplikasi web untuk mendengarkan playlist publik Suno. Tambahkan dan atur playlist melalui panel admin. Aplikasi ini tidak berafiliasi dengan Suno.

Playlist

Pengunjung dapat membuka playlist yang disediakan admin atau memasukkan tautan playlist publik.

Pemutaran offline

Pengunjung dapat menyimpan lagu di cache browser. Batas ukuran cache diatur dari panel admin.

Panel admin

Admin dapat mengelola playlist, pengaturan aplikasi, PIN login, dan PIN unduhan di panel admin.

Suno Playlist Player adalah pemutar tidak resmi dan tidak berafiliasi dengan Suno.
